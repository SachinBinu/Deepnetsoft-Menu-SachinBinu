# 🍽️ Food Menu Application

A simple full-stack web application built with **React.js**, **Node.js**, **Express.js**, and **MongoDB**.  
It provides a user-friendly interface to browse food items and includes an **Admin Panel** for adding new items.  

---

## 🚀 Features
- Frontend built with **React.js**  
- Backend powered by **Node.js** and **Express.js**  
- Data stored in **MongoDB**  
- Runs locally on **http://localhost:8080**  
- **Admin Panel** to add new food items
