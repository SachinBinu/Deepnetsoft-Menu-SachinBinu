# Food Menu Application

This is a simple web application built using **React.js** for the frontend and **MongoDB** for the backend.  
The backend is powered by **Node.js** and **Express.js**.

## Features
- User interface built with React.js  
- Backend connected to MongoDB for data storage  
- Runs locally on **http://localhost:8080**  
- Admin panel included to add new food items
